# CubeFlow

Русский · [English](README.en.md)

Сайт Эмира для изучения PLL и тренировок на настоящем кубике Рубика. Спокойный светлый интерфейс, интерактивная 3D-модель, 21 PLL и 63 варианта формул.

В шапке есть переключатель **RU / EN**. Переведены интерфейс, сообщения таймера, подсказки для каждого PLL, нотация и руководство. Выбор языка сохраняется в браузере; переключение не сбрасывает выбранную формулу, позицию анимации, избранное и результаты.

## Сначала попробуй

Распакуй архив и открой `index.html` двойным кликом. Все стили, формулы и плееры находятся внутри папки: интернет, Python и установка пакетов для работы сайта не нужны. Не перемещай `index.html` отдельно от `assets/`.

Варианты сохраняют первые два слоя и ориентацию последнего слоя. Их соответствие одному PLL проверено на модели; допускаются разные ракурсы и AUF. Для выбранного варианта плеер начинает с обращения именно этой формулы, поэтому цветовые позиции и движения согласованы.

## Опубликовать на GitHub Pages

1. Создай отдельный публичный репозиторий, например `cubeflow`. Существующий сайт олимпиады для этого не нужен.
2. Загрузи **содержимое** папки проекта в корень репозитория. `index.html`, `assets/`, `tests/`, `scripts/`, `package.json` и `.github/workflows/pages.yml` должны оказаться в корне. Сам ZIP загружать вместо файлов не надо.
3. Открой **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Открой **Actions → Deploy CubeFlow → Run workflow** и выбери основную ветку. Следующие изменения в `main` или `master` будут публиковаться автоматически. Для другого названия ветки измени `branches` в workflow.
5. Когда workflow завершится, в **Settings → Pages** появится адрес сайта. Точный адрес зависит от репозитория и настроек аккаунта.

Если загружаешь через сайт GitHub на Mac, скрытая папка `.github` может не отображаться в Finder. Нажми **⌘⇧.**, чтобы её увидеть. Альтернатива — создать `.github/workflows/pages.yml` через **Add file → Create new file**, вставив содержимое файла из архива.

Можно опубликовать и без workflow: выбрать **Deploy from a branch → main → /(root)**. В таком случае отключи workflow `Deploy CubeFlow` во вкладке Actions, чтобы он не пытался выполнить второе развёртывание. Для работы из корня сборка не нужна.

Ссылки и пути относительные: сайт работает и на домене, и в подпапке репозитория. Указанные инструкции и workflow подготовлены для GitHub Pages; публикация сама по себе не выполняется, пока файлы не загружены и Pages не включён.

Официальная документация: [источник публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), [workflow GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Возможности

- Все 21 PLL, по три варианта на каждый: T, Ua, Ub, H, Z, Aa, Ab, E, Ja, Jb, Ra, Rb, F, Ga, Gb, Gc, Gd, Na, Nb, V, Y.
- Схемы вида сверху рассчитаны из реального состояния кубика.
- Большой 3D-плеер и отдельная мини-анимация каждого варианта. Пауза, шаг вперёд/назад, шкала ходов, скорость 0.5–3×, вращение ракурса мышью или пальцем.
- Выбор любимой формулы, отметки выученных случаев, поиск и фильтры.
- Тренировка выбранных PLL: скрамбл создаётся из любимого варианта с дополнительным случайным AUF. Случаи проходят в случайном порядке без пропусков в каждом цикле.
- Таймер полных сборок 3×3 с тренировочными последовательностями случайных ходов.
- Удержание пробела 0.35 с, отпускание для старта, остановка обычной клавишей или касанием. Поддержка сенсорного экрана.
- Необязательная инспекция: при старте от 15.00 с — +2, от 17.00 с — DNF. Esc отменяет попытку. Потеря фокуса во время сборки сохраняет её как DNF.
- Личные рекорды, среднее успешных попыток, ao5/ao12 с исключением одного лучшего и одного худшего времени. При двух DNF среднее — DNF. Статистика PLL раздельная по случаю и выбранной формуле; полные сборки хранятся отдельно.
- Редактирование штрафов, просмотр скрамбла и даты, удаление с возвратом последней удалённой записи.
- CSV текущей сессии и JSON-копия всего прогресса. Восстановление JSON объединяет записи по уникальному ID, сохраняя существующие сборки.

Анимация показывает последовательность вращений, а не положение пальцев. Для освоения fingertricks полезны отдельные демонстрации на настоящем кубике. Здесь используются анимации, которые можно остановить на любом ходу; сторонние видеоплееры не требуются.

## Сохранение

Данные остаются в `localStorage` текущего браузера, в ключе `cubeflow.v1`. На другом устройстве история не появляется автоматически. Сделай JSON-копию через **С чего начать → Скачать копию JSON**, чтобы перенести её.

У локально открытого HTML и опубликованного сайта могут быть разные хранилища. При запрете сохранения, заполнении квоты или повреждённом файле сайт показывает уведомление и позволяет продолжить временную сессию без перезаписи повреждённого сохранения. Не закрывай её, пока не скачал JSON-копию.

## Для разработки

Нужен Node.js 20 или новее; зависимостей для установки нет.

```sh
npm test
npm run build
```

`build` копирует сайт в `dist/` для публикации. Сам сайт также работает из корня без сборки.

Файлы:

- `index.html` — страницы библиотеки, таймера и руководства.
- `assets/style.css` — адаптивный дизайн.
- `assets/data.js` — формулы, группы и пояснения.
- `assets/cube.js` — модель, 3D-анимация и схемы.
- `assets/stats.js` — статистика и тренировочные скрамблы.
- `assets/app.js` — интерфейс, таймер, сохранение, импорт и экспорт.
- `assets/i18n.js` — русский и английский интерфейс, перевод динамических сообщений и сохранение языка.
- `tests/` — проверки всех формул, нотации, AUF и расчётов статистики.
- `.github/workflows/pages.yml` — проверка и публикация сайта.

Чтобы получить автономный HTML с обоими языками, выполни `node scripts/export.mjs`. Он появится в `dist/CubeFlow_Preview.html`; можно также передать нужный путь первым аргументом.

Чтобы изменить название или автора, отредактируй текст в `index.html`; цвета находятся в начале `assets/style.css`. Новую формулу нужно добавлять в `assets/data.js`, затем запускать тесты.

## Источники и ограничения

3D-геометрия развивает исходный проект Эмира **Cube AI Lab 3D**. Формулы сверены с [SpeedCubeDB](https://www.speedcubedb.com/a/3x3/PLL), соответствие вариантов проверяется в тестах. [J Perm](https://jperm.net/) — дополнительный источник обучения. Порог инспекции и обработка DNF в ao5 сверены с [правилами WCA](https://www.worldcubeassociation.org/regulations/).

У каждого случая на сайте есть ссылка на дополнительные варианты. Три предложенные формулы не исчерпывают все возможные алгоритмы. Подходящий вариант зависит от хвата, кубика и техники исполнения.

Скрамблы 3×3 создаются случайными ходами, а не равномерным выбором достижимого состояния. Они предназначены для обычной практики; официальный соревновательный скрамблер здесь не реализован. Программа не проверяет, собран ли физический кубик: результат отмечает сам пользователь.
